# WizGrep

WizGrep は、Windows 向けの全文検索アプリです。Word、Excel、PowerPoint、PDF、テキストファイルを横断して検索し、結果を一覧表示できます。

## 主な機能

- 複数キーワード検索
  - 最大 5 件のキーワードを指定可能
  - AND / OR 条件を切り替え可能
  - 有効化されたキーワードのみを検索対象にする
- 検索オプション
  - 大文字小文字の区別
  - 正規表現検索
  - リアルタイム表示 / 後追い表示の切り替え
  - Excel の表示値 / 数式文字列の切り替え
  - Excel セル内改行の除去
- 対象ファイルの絞り込み
  - 標準拡張子の選択
  - カスタム拡張子の追加
  - 除外拡張子 / 除外フォルダーの指定
  - All 有効時は未対応拡張子もプレーンテキストとして読み取り
- 検索結果の操作
  - マッチしたファイル一覧の表示
  - 検索結果一覧の表示
  - ファイルを直接開く
  - 検索結果 / ファイル一覧をテキストとしてエクスポート
- 索引による高速化
  - ファイルごとの索引とタイムスタンプを保存
  - 必要に応じて索引を再構築
- テーマ切り替え
  - System / Light / Dark

## 対応ファイル形式

| カテゴリ | 拡張子 | 主な検索対象 |
|---|---|---|
| Excel (OOXML) | `.xlsx` `.xlsm` | セル値 / 数式、図形、コメント、ヘッダー/フッター、関連テキスト |
| Excel (レガシー) | `.xls` | セル値、コメント、図形テキスト |
| Word (OOXML) | `.docx` `.docm` | 本文段落、VML シェイプ、ヘッダー/フッター、コメント、リンク関連テキスト |
| Word (レガシー) | `.doc` | 本文テキスト |
| PowerPoint (OOXML) | `.pptx` `.pptm` | スライドのシェイプ・テーブル・チャート、ノート、関連テキスト |
| PowerPoint (レガシー) | `.ppt` | スライドテキスト |
| PDF | `.pdf` | ページごとのテキスト、注釈、ブックマーク、フォーム項目、文書情報 |
| テキスト | `.txt` | 行単位テキスト |

> 既定では、上記の拡張子を検索対象にします。`All` を有効にした場合は、未対応拡張子も含めて検索します。

## 使い方

1. メイン画面の **Grep Settings** を開きます。
2. **検索フォルダー** に対象フォルダーを指定します。初期値は「ドキュメント」です。
3. キーワードを 1 つ以上入力し、必要に応じて AND / OR を切り替えます。
4. 対象ファイル種別、拡張子、除外条件、検索オプションを設定します。
5. **検索開始** を実行すると、フォルダー配下を再帰的に検索します。
6. 左側にマッチしたファイル、右側に詳細結果が表示されます。
7. 結果をダブルクリックすると、そのファイルを開けます。
8. 必要に応じて、ファイル一覧や検索結果をテキストとしてエクスポートします。

## 設定

### Grep Settings

| 項目 | 説明 |
|---|---|
| キーワード 1〜5 | 最大 5 件のキーワードを登録できます。チェックを外したキーワードは検索に使われません。 |
| AND / OR | すべて一致で検索するか、いずれか一致で検索するかを切り替えます。 |
| 検索フォルダー | 検索対象のルートフォルダーです。 |
| 対象ファイル種別 | Excel / Word / PowerPoint / PDF / Text / All を選択できます。 |
| カスタム拡張子 | `.csv, .xml, .json` のように追加対象を指定できます。ドットは省略可能です。 |
| 除外拡張子 | `.tmp, .bak, .log` のように除外対象を指定できます。 |
| 除外フォルダー | セミコロン区切りで除外フォルダーを指定できます。相対パスも利用できます。 |
| 正規表現 | キーワードを .NET 正規表現として扱います。 |
| 大文字小文字を区別 | 大文字小文字を区別して検索します。 |
| リアルタイム表示 | 見つかった結果を検索中に順次追加します。 |
| 表示値で検索 / 数式で検索 | Excel の表示値または数式文字列を検索対象にします。 |
| セル内改行を除去 | Excel の結果表示時に改行をスペースへ置換します。 |

### WizGrep Settings

| 項目 | 説明 |
|---|---|
| インデックス保存先 | 検索インデックスの保存先です。未設定時はローカルアプリデータ配下の `WizGrep\Index` が使われます。 |
| インデックスを再構築 | 次回検索時に既存の索引を削除して作り直します。 |
| エクスポートに検索条件を含める | エクスポート先ファイルの先頭に検索条件を付与します。 |
| テーマ | System / Light / Dark を切り替えます。 |

## インデックスについて

WizGrep は、検索対象フォルダーごとにファイル単位の索引とタイムスタンプを保存します。前回の検索から更新されていないファイルは、索引を使って再読込を省略できます。

索引の保存先が未設定の場合は、`%LocalAppData%\WizGrep\Index` が既定値として使われます。`インデックスを再構築` を有効にすると、次回検索開始時に対象フォルダーの索引が削除され、再生成されます。

## 設定の保存

検索設定と WizGrep 設定は、Windows のローカルアプリ設定に JSON として保存されます。アプリ再起動時に自動で復元されます。

## 開発環境

- .NET 10
- WinUI 3 / Windows App SDK
- Visual Studio Community 2026 以降を推奨
- 対応プラットフォーム: x86 / x64 / ARM64

## ビルド

Visual Studio で `WizGrep.slnx` を開いてビルドします。

CLI からは次のように実行できます。

```powershell
dotnet build .\WizGrep.slnx
```

## 補足

- 旧形式の `.doc` / `.xls` / `.ppt` に対応しています。
- テキストファイルは、コードページ対応を有効化したうえで読み取ります。
- 検索結果の位置情報には、行番号、シート名、セルアドレス、オブジェクト名などが含まれます。
